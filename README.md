## 功能

### 拍照
- 取景框里实时显示水印，所见即所得：预览和成片用同一套绘制代码。
- 画幅 4:3 / 16:9 / 1:1 / 全屏；变焦、点按对焦、曝光补偿、闪光灯、前后摄像头；手机支持时可用夜景、HDR 等厂商模式。
- **照片分辨率**：最高（高像素模式，如 5000 万像素传感器的全尺寸输出）/ 1200 万 / 800 万 / 500 万 / 300 万。手机不支持最高像素模式时自动退回 1200 万并提示。
- **JPEG 质量** 60–100 可调。
- **同时保存原图**：每次拍照另存一张无水印原图到 `Pictures/GeoTagCamera/原图`，重拍时一并删除。
- 拍完的预览页显示照片实际像素和文件大小。

### 水印内容
- **自定义字段**：每个字段在水印上显示为一行"名称：内容"，例如"施工区域：右岸坝肩""施工内容：船闸及非溢流坝区域石方开挖"。默认有"施工区域""施工内容"两个字段，可增删、改名、排序、单独隐藏；内容为空的字段不显示。
- **预设**：每个字段可以存多条常用内容。在设置里逐条添加或一次粘贴多行；拍照时点取景框下方的字段卡，一点即选。拍过的内容自动进入"最近"，不需要的可以点 × 删除。
- **日期时间**：12 种预设格式（星期显示为中文），也可以自己写格式串；时间前可加名称，如"拍摄时间：2026.10.29 18:12:46"。
- **自定义拍摄时间**：开启后水印、照片 EXIF 和相册记录都使用设定的时间，时钟从设定时间继续走；开启期间取景框上一直有提示。
- 可选显示：地址、经纬度、国家代码、时区、海拔、定位精度、方向、天气、地图缩略图、单位名称和 Logo、固定文字。

### 水印样式
- 两种模板：**信息栏**（贴在照片顶部或底部）和 **简洁**（只显示字段、坐标和时间，可放在九宫格任意位置）。
- 水印大小 50%–250%，左右/上下边距，九宫格位置；也可以在取景框里长按水印拖动。
- 背景色、文字色（预设色板或自选），背景和文字的不透明度分别可调；背景很淡时文字自动加阴影。
- **长文字换行**：开启时内容放不下就换到下一行，完整显示；关闭时严格单行，不换行、不省略、不缩字号，水印框随最长一行变宽。任何情况下文字都不会被省略号截断。

### 本地照片加水印
- 底部导航的"加水印"页，或拍照界面右上角的入口。一次可选多张。
- 拍摄时间优先读取照片 EXIF（DateTimeOriginal，含时区偏移）；没有时间的照片标红，需手动设置，可一次套用到所有缺时间的照片。
- 照片带 GPS 的会显示坐标和地址；没有 GPS 的不显示坐标。
- 水印样式、字段、日期格式沿用设置。原图不改动，新图存到 `Pictures/GeoTagCamera/本地水印`，并写入设定的时间、GPS 和原照片的相机参数。
- 这些照片不是本应用拍摄的，所以**不做签名证明**，也不进入应用内相册。

### 相册、项目与导出
- 应用内相册显示每张照片的校验状态（已验证 / 拍摄后被修改）。
- **按项目分组**（默认关闭，在 设置 → 拍照 → 拍摄 里开启）：选定当前项目后，新照片自动归入；相册可按项目筛选。项目不会显示在水印上。
- 导出位置数据：CSV（Excel、WPS）、KML（奥维地图、Google Earth、两步路）、GeoJSON（QGIS、ArcGIS）。
- 生成 PDF 现场照片报告，每张照片附时间、地点、坐标和校验结果。
- 离线地图：提前下载区域，没信号时水印地图也能显示。

## 安装

1. 在手机上打开 [Releases 页面的最新正式版](https://github.com/chazai233/geotagcamera/releases/latest)，下载 `GongChengCamera-版本号.apk`。
2. 安装时如提示"未知来源"，按提示允许浏览器或文件管理器安装应用。
3. 以后的新版本直接覆盖安装，设置和照片都会保留。

版本说明：
- **正式版**：标签形如 `v1.4.1-cn2`，永久保留；发行说明里写明对应的源码提交、签名证书指纹和文件 SHA-256。
- **测试版**：标签 `cn-latest`，每次推送代码后自动更新，用于试用新改动。正式版和测试版用同一把密钥签名，可以互相覆盖安装。
- **1.4.1-cn1 及更早的版本**用的是公开的调试密钥，已经作废。装过这些版本的手机需要先卸载再安装新版；系统相册里的照片不受影响，应用内的字段、预设和设置需要重新填写。

说明：
- 包名为 `com.geotagcamera.geotagginglocationonphoto.cn`，可以和原版 GeoTag Camera 同时安装，互不影响。
- 支持 Android 8.0 及以上，不需要 Google Play 服务。

## 与原版的区别

| 项目 | 原版 GeoTag Camera | 本中文版 |
|---|---|---|
| 界面语言 | 英文 | 中文（界面、水印、PDF 报告、导出文件） |
| 照片分辨率 | 固定上限约 1200 万像素 | 5 档可选，含最高像素模式 |
| 原图 | 不保存 | 可选同时保存无水印原图 |
| 水印内容 | 固定字段 + 一条备注 | 自定义字段 + 预设 + 最近记录 |
| 水印样式 | 固定颜色和大小 | 大小、颜色、不透明度、边距、换行方式可调 |
| 日期时间 | 固定格式 | 12 种格式 + 自定义格式 + 时间前名称 |
| 拍摄时间 | 手机当前时间 | 可手动设定（见下方签名说明） |
| 本地照片 | 不支持 | 可给已有照片批量加水印 |
| 项目分组 | 默认显示 | 默认关闭，可在设置中开启 |

## 防篡改签名

拍照时，应用对照片画面计算 SHA-256 哈希，并连同拍摄的纬度、经度、时间一起，用手机安全密钥库中生成的 ECDSA P-256 密钥签名；证明写入照片的 EXIF 和 XMP。任何装有本应用的手机都可以在"校验照片"中离线验证。

- **验证通过**表示：照片画面（含水印）以及 EXIF 中的经纬度和时间，自签名后没有被改动。
- **手动设定了拍摄时间的照片**：EXIF 和水印使用设定的时间；签名证明同时记录按下快门的真实时间（证明格式 v3）。校验时会显示"拍摄时间是手动设定的"以及实际按快门的时间，不会把设定时间当作真实时间来证明。
- 签名不能证明拍照的人是谁，也不能证明 GPS 和手机时钟本身是准确的。
- 聊天软件转发时通常会重新压缩并删除元数据，照片就无法通过校验。需要校验时请发送原文件。
- 本地照片加水印功能产生的照片不带签名。

原版签名机制的完整说明见 [README.en.md](README.en.md#how-photo-verification-works)。

## 从源码编译

### GitHub Actions（推荐）
[CN Build](.github/workflows/cn-build.yml) 工作流：
- 推送到 `main`：运行单元测试，编译正式签名的 APK，更新测试版 `cn-latest`。
- 推送标签 `v版本号`（须与 `app/build.gradle.kts` 的 versionName 一致）：发布永久保留的正式版，发行说明取自 [CHANGELOG_CN.md](CHANGELOG_CN.md) 对应版本的一节。
- 编译失败时，构建日志推送到 `ci-logs` 分支。

签名密钥只从仓库的 Actions Secrets 读取（`KEYSTORE_BASE64`、`KEYSTORE_PASSWORD`、`KEY_ALIAS`、`KEY_PASSWORD`），仓库里不存放任何密钥。没有配置时只运行测试，不发布 APK。

### 本地编译
需要 JDK 17 和 Android SDK（platform 36）。

```
git clone https://github.com/chazai233/geotagcamera.git
cd geotagcamera
./gradlew testFossDebugUnitTest assembleFossDebug
```

APK 在 `app/build/outputs/apk/foss/debug/`，使用你本机的 Android 调试密钥签名，不能覆盖安装 Releases 里发布的版本。
